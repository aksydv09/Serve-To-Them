# Serve To Them – Community Service Discovery Platform

[![Django](https://img.shields.io/badge/Django-4.x-green.svg)](https://www.djangoproject.com/)
[![Python](https://img.shields.io/badge/Python-3.9%2B-blue.svg)](https://www.python.org/)
[![Database](https://img.shields.io/badge/Database-MySQL%20%7C%20SQLite3-orange.svg)](#)
[![Bootstrap](https://img.shields.io/badge/Frontend-Bootstrap%205-purple.svg)](#)

A full-stack community service web application designed to connect service seekers with local service providers. Features role-based access control, dynamic multi-parameter search, and secure user management.

---

## 🚀 Key Features

* **Role-Based Access Control (RBAC):** Distinct dashboards and access layers for service seekers, staff, and administrators.
* **Dynamic Search & Filtering:** Filter service providers by category, availability, and rating with optimized ORM queries.
* **Profile Management:** User profile updates with media uploads and application tracking.
* **Responsive UI:** Clean, mobile-friendly interface built with Bootstrap 5 and Django Jinja templates.

---

## 🛠️ Tech Stack

* **Backend:** Python, Django (MVT Architecture)
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
* **Database:** SQLite3 / MySQL with Django ORM
* **Version Control:** Git, GitHub

## ⚙️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/aksydv09/Serve-To-Them.git](https://github.com/aksydv09/Serve-To-Them.git)
   cd Serve-To-Them
   ```

2. **Install dependencies:**
   ```bash
   pip install django
   ```

3. **Apply migrations:**
   ```bash
   python manage.py migrate
   ```

4. **Run the server:**
   ```bash
   python manage.py runserver
   ```
   Open `http://127.0.0.1:8000/` in your browser.
